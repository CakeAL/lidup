# lidup

一个 macOS **菜单栏（托盘）小工具**，用 Rust 编写。

它的作用：当你连接了一块**指定的外接显示器**时，自动**关闭 MacBook 的内建显示器**；当你**拔掉它**时，自动把内建显示器**点亮**。同时也可以在托盘菜单里**手动开关任意一块显示器**（内建或外接）。

---

## 下载
https://github.com/CakeAL/lidup/releases

### 托盘菜单

运行后，右上角菜单栏会出现 lidup 图标，菜单包含：

- **自动关闭内建屏** — 选择哪块外接显示器作为触发显示器（选「不自动关闭」则关闭自动功能）。选中后：
  - 插入该外接显示器 → 自动关闭内建屏；
  - 拔掉该外接显示器 → 自动点亮内建屏。
- **显示器** — 勾选表示已开启；点击对应显示器可手动切换。
- **登录时启动** — 开机自启（注册登录项）。
- **检查更新…** — 检查 GitHub 的最新正式 Release；有新版本时可从菜单下载安装并重启。
- **退出 lidup** — 退出，并恢复内建显示器。

---

## 说明

- 「自动关闭」只在选择绑定某块外接屏后生效；绑定显示器插上时内建屏保持关闭，拔掉时自动点亮。
- 为避免睡眠唤醒期间外接屏短暂离线引发误操作，自动恢复内建屏会等待外接屏持续缺席约 5 秒。
- 你在菜单里**手动**开关某一台显示器后，自动功能会被置为 `None`，不再干扰你的手动操作。
- 为安全起见，lidup 不会让所有显示器同时熄灭——总会保证至少有一块是点亮的。
- 启动时及之后每 24 小时在后台检查一次更新，也可从菜单手动重试。点击 **Install** 后，`self_update` 下载 Release 中的 `lidup.zip`，验证签名并替换当前 `.app`；安装完成后点击 **Restart**。安装失败会在菜单中显示，不会影响显示器控制。更新需要当前应用所在目录可写。

## 配置

设置保存在 `~/Library/Application Support/lidup/config.json`（可用 `LIDUP_CONFIG` 环境变量改路径）。

## 开发

### 构建并运行

需要安装 Xcode 命令行工具和 Rust 工具链。

```sh
./pack.sh                       # 打包成菜单栏应用（无 Dock 图标）
open target/release/lidup.app   # 运行
```
